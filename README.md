## 搬瓦工的"带宽"是什么：先把概念说清楚

搬瓦工标注在套餐里的带宽数字，是这台 VPS 的**带宽上限（接入带宽）**。你可以理解成：这台机器接的网线最大能跑多快。

但不是独享。

搬瓦工的带宽是**共享带宽**——一台物理母机上跑着多个 VPS 实例，网络资源是大家一起用的。这一点搬瓦工没有刻意隐瞒，这也是 VPS 行业的普遍做法，和"专用服务器"不是一回事。

说这个不是要吓你。重要的是：**共享带宽的质量差异，取决于主机商的超售程度和机房线路质量**，而不仅仅是那个数字。

标称带宽上限高 → 分配给每台 VPS 的基础带宽更充裕 → 冲突时的带宽余量更大。这也是 CN2 GIA-E 套餐起步就给 2.5 Gbps 的意义所在：即便是共享，底子就比同行 1 Gbps 的方案宽得多。

## 带宽数字背后，真正影响速度的是线路

顺便提一嘴，很多人盯着带宽数字没抓住关键。

决定你用起来快不快，80% 在线路，20% 才是带宽上限。搬瓦工在这块的逻辑很清晰：

**CN2 GT（单程）**：去程走 CN2 精品网，回程进国内后走的是 163 骨干网。意思是晚高峰回程可能堵，因为 163 是大家共用的通道。

**CN2 GIA（双程）**：去程回程全程走中国电信 CN2 GIA 节点（能看到全是 59.43 开头的路由节点）。这条线路有独立的回国链路，属于轻载，高峰期也基本不受影响。联通和移动用户用 CN2 GIA 同样走 CN2 回国，比自己运营商的直连稳定得多。

所以搬瓦工平均带宽的问题，不能脱离线路单独谈。

同样是"1 Gbps 带宽"，CN2 GT 在晚高峰和 CN2 GIA 体验差距可能是几倍。数字一样，路不一样。
